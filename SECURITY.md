# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, private estate
metadata, or exploit details in a public issue.

Use the repository's private vulnerability reporting channel:

https://github.com/szl-holdings/szl-estate-os/security/advisories/new

Include the affected version or commit, reproduction steps, expected impact,
and any known mitigations. Do not include live secrets. Revoke or rotate an
exposed credential through its provider before sharing a redacted report.

## Supported state

Security support applies to the current default branch. Audit results marked
`MODELED`, `PARTIAL`, or `UNAVAILABLE` are not production-security proof.
