# Synthetic Action Assurance Fixtures

These files exercise the local validator and CI workflow only.

- `passports/execute.json` models an approved, review-branch action.
- `passports/refuse.json` models a blocked protected-branch mutation.
- `citations.current.json` is a synthetic drift-check fixture using
  `example.com`; it is not production research or evidence for an external
  claim.

Do not present fixture counts, timestamps, decisions, scores, or source URLs as
live estate measurements.
