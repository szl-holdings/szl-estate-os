Boundaries & provenance

Know the scope.

G

GitHub

Repository enumeration is distinct from a file audit. Workflow definitions, individual checks, review conversations and complete deployment evidence are outside this view.

H

Hugging Face

Readme and immutable file metadata were observed. Other file contents, model quality, training, application contracts and signer validity were not audited.

L

Local estate

Discovery had depth and directory exclusions. Untracked files, nested repositories inside discovered roots and current remote heads were not audited.

Inspect source inventory hashes

SHA-256 binds this view to the exact source files used at build time. A digest does not establish signer identity or immutable external custody.
